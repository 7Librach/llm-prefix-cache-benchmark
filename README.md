# Влияние кэширования общего префикса запросов на время отклика локальной языковой модели

Экспериментальный стенд и первичные данные измерений для оценки эффективности кэширования префикса (KV-кэша) в `llama.cpp` на графическом ускорителе NVIDIA GeForce RTX 2080 SUPER (8 ГБ) для моделей семейства Qwen2.5 (`1.5B`, `3B`, `7B`, квантизация `Q4_K_M`).

## Конфигурация стенда

- **Процессор:** Intel Core i9-9900K, 16 ГБ ОЗУ
- **Видеокарта:** NVIDIA GeForce RTX 2080 SUPER (8 ГБ GDDR6)
- **Среда инференса:** `llama.cpp` b11960 (CUDA 12.4)
- **Параметры запуска `llama-server`:**
  ```bash
  llama-server -m <путь_к_gguf> --port 9931 -ngl 99 -c 8192 -b 2048 -ub 512 -np 1 -t 8 -tb 8 -fa on --cache-prompt --cache-ram 0
  ```

## Структура репозитория

- `bench.py` — основной скрипт проведения парных замеров времени обработки входного запроса (`cache_prompt = false` / `cache_prompt = true`) при длинах префикса `128, 256, 512, 1024, 2048, 4096` токенов и независимых суффиксах длины `128` токенов.
- `bench_suffix.py` — замеры при фиксированном префиксе (`1024` токена) и варьировании длины нового суффикса (`32, 64, 128, 256, 512` токенов).
- `analyze.py` — расчёт статистик, линейной регрессии (МНК), критериев Уилкоксона и Фридмана, построение графиков.
- `results/` — первичные данные всех серий измерений (`.json`), сводные таблицы (`.csv`) и графики.
  - `raw_1_5b_v2.json`, `raw_3b_v2.json`, `raw_7b_v2.json` — основная серия (полностью различные суффиксы, `n_выч = 128`, `n_кэш = n_преф + 1`).
  - `raw_1_5b.json`, `raw_3b.json`, `raw_7b.json` — сравнительная серия при почти полном совпадении запросов (`n_выч = 7`).
  - `raw_suffix_3b.json` — серия с варьированием длины суффикса на модели `Qwen2.5-3B`.

## Запуск

1. Запустить `llama-server` с нужной моделью.
2. Запустить замеры:
   ```bash
   python bench.py --model D:/llm/models/qwen2.5-1.5b-instruct-q4_k_m.gguf --repeats 10 --out results/raw_1_5b_v2.json
   ```
3. Построить сводную таблицу и графики:
   ```bash
   python analyze.py
   ```
